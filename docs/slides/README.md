# 採用サイト運用ガイド スライド

新メンバー向けのオンボーディング用スライド資料です。
Google Meet で画面共有しながら使うことを想定しています。

## ファイル

| ファイル | 用途 |
|---|---|
| `採用サイト運用ガイド.pptx` | 完成スライド（PowerPoint / Google Slides で開く） |
| `generate.js` | スライド生成スクリプト（再生成・編集用） |

## 使い方

### Google Meet で共有
1. `採用サイト運用ガイド.pptx` を PowerPoint または Google Slides で開く
2. Meet で画面共有 → 全画面表示
3. 1スライド3〜5分目安、全16スライドで約45〜60分

### Google Slides にインポート
1. Google ドライブにアップロード
2. ファイルを右クリック → 「アプリで開く」→ Google Slides
3. 共有設定でメンバーに「閲覧者」権限付与
4. 後でブラウザだけで見れるように

## 再生成・編集

文言や色を変更したい場合:

```bash
cd C:\recruit-mock\docs\slides
node generate.js
```

→ `採用サイト運用ガイド.pptx` が再生成されます

### よくある編集

`generate.js` 内の `C` オブジェクトでカラー変更:
```javascript
const C = {
  green: '7FCC30',      // ブランドメイン
  darkGreen: '1A4D2E',  // タイトル背景
  ...
};
```

各スライドはコメント `// === スライド N: ... ===` で区切られているので、
該当箇所を編集してください。
